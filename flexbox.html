Flexbox

O Flexbox é um modelo de layout do CSS que permite organizar elementos em uma direção (linha ou coluna) e distribuir espaço entre eles de forma flexível, facilitando o alinhamento.

Vamos ver as principais propriedades do Flexbox:

  • flex-direction - Define a direção dos itens (linha ou coluna);
  • justify-content - Alinha os itens horizontalmente;
  • align-items - Alinha os itens verticalmente;
  • flex-wrap - Permite que os itens quebrem para a próxima linha;
  • align-content - Alinha linhas de itens quando há espaço extra.
